# Open space weather feeds

All of these are public. No API key.
Primary source: NOAA Space Weather Prediction Center
https://www.swpc.noaa.gov/content/data-access
Base: https://services.swpc.noaa.gov

## Used first (reliable, live)

| What | URL |
|---|---|
| Aurora oval (OVATION grid) | https://services.swpc.noaa.gov/json/ovation_aurora_latest.json |
| Aurora still (north) | https://services.swpc.noaa.gov/images/animations/ovation/north/latest.jpg |
| Aurora still (south) | https://services.swpc.noaa.gov/images/animations/ovation/south/latest.jpg |
| NOAA R/S/G scales | https://services.swpc.noaa.gov/products/noaa-scales.json |
| Planetary Kp | https://services.swpc.noaa.gov/products/noaa-planetary-k-index.json |
| Kp forecast | https://services.swpc.noaa.gov/products/noaa-planetary-k-index-forecast.json |
| 10.7 cm solar flux | https://services.swpc.noaa.gov/products/summary/10cm-flux.json |
| GOES X-ray | https://services.swpc.noaa.gov/json/goes/primary/xrays-6-hour.json |
| Solar wind speed | https://services.swpc.noaa.gov/products/summary/solar-wind-speed.json |
| IMF Bt / Bz | https://services.swpc.noaa.gov/products/summary/solar-wind-mag-field.json |
| Kyoto Dst | https://services.swpc.noaa.gov/products/kyoto-dst.json |
| Alerts | https://services.swpc.noaa.gov/products/alerts.json |
| 3-day forecast text | https://services.swpc.noaa.gov/text/3-day-forecast.txt |
